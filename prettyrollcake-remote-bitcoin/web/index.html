Remote Bitcoin

別ホストの bitcoind を、Lightning Node（LND）や Core Lightning の Bitcoin ノードとして使います。

接続先

.local の名前はコンテナ内で引けないので IP がおすすめ
その他のポート（ふつうは変更不要）

接続テストの結果

使い方

  1. 上で接続先を入れて「接続テスト」→「保存」。
  2. Lightning Node・Core Lightning・Electrs などをインストールするとき、Bitcoin Node の代わりに Remote Bitcoin を選ぶ。
  3. 設定を変えたら、それを使うアプリ（Lightning Node など）を再起動すると反映されます。

別ホストの bitcoin.conf の例（rpcauth は bitcoind 付属の share/rpcauth/rpcauth.py で作成）:

server=1
rpcbind=0.0.0.0
rpcallowip=<Umbrel の IP>/32
rpcauth=<ユーザー名>:<ハッシュ>
# LND で必要（Core Lightning では不要）
zmqpubrawblock=tcp://0.0.0.0:28332
zmqpubrawtx=tcp://0.0.0.0:28333
# Fulcrum・ElectrumX で必要
txindex=1
# Electrs はブロックを P2P（8333）で取得する
listen=1
whitelist=download@<Umbrel の IP>
