    トークンと API

    クライアントごとにトークンを1つ作り、すべてのインボイスで使い回します。トークンで見えるのは、そのトークンで作ったインボイスの支払い状態だけです。このページも、ブラウザに保存した下のトークンを使っています。

    トークンはこのブラウザの中で作り、リレーにはハッシュだけが残ります。英数字・-・_ で 32 文字以上なら、自分で作ったものでも使えます（例：openssl rand -hex 32）。
