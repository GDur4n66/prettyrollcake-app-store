Remote Electrum

別ホストの Electrum サーバ（Electrs・Fulcrum・ElectrumX）を、Mempool などから Electrs の代わりに使います。

接続先

.local の名前はコンテナ内で引けないので IP がおすすめ
ふつうは TCP 50001、SSL 50002
自己署名の証明書なら外したままにする

使い方

  1. 上で接続先を入れて「接続テスト」→「保存」。
  2. Mempool などをインストールするとき、Electrs の代わりに Remote Electrum を選ぶ。
  3. 接続先を変えたときは保存するだけで、次の接続から新しい接続先が使われます（Mempool などの再起動は不要）。

アプリはこのアプリの中継（Umbrel 内、暗号化なし）につなぎ、中継が別ホストへ TCP か SSL でつなぎ直します。
